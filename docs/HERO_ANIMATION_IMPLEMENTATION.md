# Animated scientific hero banner

The original `assets/portfolio-v2-hero.svg` is preserved as a static fallback. `assets/portfolio-v2-hero-animated.svg` reuses its original vectors, adding declarative SVG path motion and CSS stroke animation. The webpage uses JavaScript to switch images with a visible play/pause control, respecting reduced-motion preferences. No GIF conversion or external animation library is necessary.

Scientific semantics: P → T means charging availability; T → P means transportation-supported repair access. Moving pulses and the Y(t) marker are **conceptual presentation cues (tau_ui)**, not measured flows, delay estimates, calibrated physics, or the solution to a governing ODE. The drawn viable region is a schematic, not a computed viability kernel. A real physical animation must instead solve documented differential equations, define units, use evidence-based parameters, and compare numerical output against observations.

Verification: `npm run verify:hero-banner`, `npm run verify`. All original research content and approved text remain unchanged.
